# Security Policy

LogicFlow is a student open-source web project and is currently under development.

## Reporting a Vulnerability

Please do not report suspected vulnerabilities in a public issue. Use GitHub's private vulnerability reporting feature for this repository if it is enabled. If it is not available, contact a project maintainer privately through a channel listed on the repository profile. Do not include sensitive information in a public report.

When reporting an issue, include:

- A clear description of the potential vulnerability and its possible impact.
- The affected page, file, feature, or browser environment, if known.
- Steps to reproduce the issue, including any required input or configuration.
- A minimal proof of concept or screenshot, if it can be shared safely.
- Any suggested mitigation, if you have one.

The project team will review reports and may ask for additional details. Please allow maintainers time to investigate before publicly disclosing a vulnerability.

## Sensitive Information

Never commit or publish passwords, API keys, access tokens, private keys, personal data, or other sensitive information. Do not include real credentials in examples, screenshots, test data, or issue reports. If a secret is accidentally exposed, revoke or rotate it immediately and notify the maintainers privately.
